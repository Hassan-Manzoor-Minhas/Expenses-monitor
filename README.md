# 💰 Expense Tracker

A full-stack expense tracker built with the MERN stack (MongoDB, Express, React, Node.js). Sign up, log in securely, and manage your income and expenses with charts, filters, budgets, and dark mode.

## ✨ Features

- Secure signup and login with JWT and bcrypt
- Add, edit, and delete income and expense transactions
- Each user sees only their own data
- Dashboard with total income, expenses, and balance
- Spending by category and monthly income vs expense charts
- Filter by month and category, plus search by title
- Budget tracker
- Export and import transactions
- Responsive layout with dark mode

## 🛠️ Tech Stack

- **Frontend:** React (Vite), Tailwind CSS, React Router, Axios, Recharts
- **Backend:** Node.js, Express
- **Database:** MongoDB with Mongoose
- **Auth:** JWT, bcryptjs
